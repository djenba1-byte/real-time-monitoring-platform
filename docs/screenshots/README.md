# Screenshots

These images are real captures from the locally running Docker Compose stack.
They are included as implementation evidence, not generated UI mockups.

| File | What it shows |
| --- | --- |
| `dashboard.png` | Live dashboard, system health, metrics, trend chart, and alert lifecycle events. |
| `prometheus-alert-rules.png` | Prometheus rule groups and configured alert expressions. |
| `alertmanager-routing.png` | Active `PortfolioEndToEndDemo` alert routed to the `monitoring-app` receiver. |
| `docker-compose-stack.png` | Running application, Prometheus, and Alertmanager containers and exposed ports. |

The dashboard image is used as the primary README screenshot because it shows
the operational result of the full stack in one view.
